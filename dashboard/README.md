# End-User Dashboard

The repository dashboard is intended to demonstrate the project to multiple user groups rather than expose only model metrics.

## Views

- Executive command center
- AML operations
- Investigator workbench
- Model risk / governance
- Data science / ML
- AI investigation
- Portfolio / interview

## Core dashboard metrics

- 100,000 payment edges
- 36,979 accounts
- 0.972667 ROC-AUC
- 0.554988 PR-AUC
- 30,000 evidence records
- 1,000 selected investigations
- 100% model/transaction/network/behavior evidence coverage
- 0 explicit ground-truth contamination
- 32 successful persisted AI investigations

## Local execution

The dashboard source is in `src/dashboard.py`. The notebook `04_END_USER_DASHBOARD.ipynb` is the easiest entry point for an interactive notebook demonstration.
