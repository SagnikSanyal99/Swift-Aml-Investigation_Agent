# 04 — End-User Dashboard

The project includes an interactive dashboard designed for
different users across the AML investigation lifecycle.

## Executive / Risk Leadership

Provides a consolidated view of:

- payment and account scale;
- model performance;
- investigation workload;
- priority and case-type distribution;
- evidence availability;
- validation and governance status.

## AML Operations

Provides:

- investigation queue;
- priority distribution;
- case types;
- evidence availability;
- workload composition.

## AML Investigator

Provides:

- individual case selection;
- model signal;
- transaction context;
- network context;
- behavioral context;
- supporting evidence;
- case-level review.

## Compliance / Model Risk

Provides:

- train/test separation;
- frozen-model status;
- checkpoint integrity;
- evidence isolation;
- ground-truth controls;
- validation results.

## Data Science / AI

Provides:

- model metrics;
- controlled experiment results;
- evidence composition;
- retrieval coverage;
- AI investigation prototype results.
