# Stakeholder-Facing Investigation Agent

## What the stakeholder is seeing

The public demonstration turns the validated AI investigation layer into an understandable workflow for a non-technical user.

The stakeholder does not need to understand graph learning, model architecture, or API implementation. They see the operational sequence:

```text
Case selected
     ↓
Why the case is under review
     ↓
Evidence available
     ↓
AI-assisted investigation
     ↓
Evidence-cited work product
     ↓
Human review / next action
```

## What the underlying project has validated

- 1,000 selected investigation cases
- 30,000 canonical evidence records
- 30 evidence records per case on average
- 100% model signal coverage
- 100% transaction context coverage
- 100% network context coverage
- 100% behavioral context coverage
- 100% multi-source evidence coverage
- 100% GOOD/RICH evidence coverage
- 0 explicit ground-truth contamination
- 32 persisted successful AI investigations
- 100% fully cited successful findings
- 0 invalid evidence citations

## Public demonstration boundary

The private text of the 32 successful AI investigations is not distributed in the public repository. The stakeholder page therefore demonstrates the workflow and uses only validated project-level facts. It does not invent case-specific findings.

## Human oversight

The stakeholder remains the decision maker. The demonstration supports review, evidence inspection, escalation, and requests for additional information rather than automatic case closure.
