# Investigation Workflow

```text
Payment event
      ↓
Predictive model signal
      ↓
Case selection / prioritization
      ↓
Canonical evidence retrieval
      ↓
Transaction + network + behavioral context
      ↓
Investigator review
      ↓
Evidence-backed case analysis
      ↓
AI-assisted synthesis where available
      ↓
Auditable case record
```

## Validated evidence layer

For 1,000 selected cases:

- 30,000 canonical evidence records
- 30 records per case on average and median
- 100% model signal coverage
- 100% transaction context coverage
- 100% network context coverage
- 100% behavioral context coverage
- 100% minimum-evidence coverage
- 100% multi-source coverage
- 100% GOOD/RICH evidence coverage
- 0 explicit ground-truth contamination
